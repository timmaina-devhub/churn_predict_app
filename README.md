# Churn Prediction FastAPI

A FastAPI-based machine learning API for customer churn prediction deployed using Docker on Hugging Face Spaces.

## Endpoints

* `/docs` → Swagger UI
* `/predict_churn` → Prediction endpoint

## Tech Stack

* FastAPI
* Scikit-learn
* Docker
* Hugging Face Spaces
